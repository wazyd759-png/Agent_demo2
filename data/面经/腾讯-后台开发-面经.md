# 腾讯 后台开发 面经

## 岗位信息

- 部门：微信支付
- 岗位：后台开发工程师
- 面试轮次：3 轮技术 + 1 轮 HR

## 一面（50 分钟）

### C++ 基础

- 虚函数的实现原理
- 智能指针有哪些，shared_ptr 的循环引用怎么解决
- STL 中 vector 和 list 的区别，各自适用场景
- 内存泄漏怎么排查

### 网络

- TCP 三次握手、四次挥手
- TIME_WAIT 状态的作用
- HTTP 和 HTTPS 的区别
- HTTPS 的握手过程

### 操作系统

- 进程和线程的区别
- 进程间通信有哪些方式
- 死锁的四个必要条件

### 算法

- 反转链表
- 二叉树层序遍历

## 二面（70 分钟）

### 系统设计

- 设计一个支付系统，要求高可用、强一致
- 如何保证分布式事务的一致性
- 幂等性怎么保证
- 对账系统怎么设计

### 项目深挖

- 你项目里最难的技术点是什么
- 如果重新做，你会怎么改进
- 你在这个项目里的角色和贡献

### 算法

- 一道 DP：最长递增子序列
- 一道图论：拓扑排序

## 三面（40 分钟，组长）

- 你怎么理解支付系统的安全性
- 如果线上出现资损，你的排查思路
- 你怎么看微信支付和支付宝的差异
- 反问

## 面试总结

### 考察重点

1. 基础扎实：C++、网络、操作系统是重点
2. 金融场景：支付系统对一致性、安全性要求极高
3. 工程规范：代码质量、测试覆盖、监控告警
4. 责任意识：涉及资金，容错率极低

### 准备建议

- 复习《深入理解计算机系统》
- 熟悉分布式事务（2PC、TCC、Saga）
- 了解支付业务的基本流程
- 准备一个高并发项目的详细讲解

### 结果

三面通过，HR 面后拿到 offer。
