# 美团 数据分析 面经

## 岗位信息

- 部门：到店事业群
- 岗位：数据分析师
- 面试轮次：2 轮技术 + 1 轮业务 + 1 轮 HR

## 一面（45 分钟）

### SQL

- 写一个 SQL：查询每个城市订单量前 10 的商家
- 窗口函数有哪些，rank 和 dense_rank 的区别
- 如何优化一个慢查询

### 统计基础

- 假设检验的基本流程
- P 值的含义
- AB 测试怎么设计，样本量怎么计算

### 业务

- 如果某天订单量突然下降 10%，你怎么排查
- 你会看哪些指标，怎么拆解

## 二面（60 分钟）

### 案例分析

- 美团到店业务想提升用户复购率，你会怎么做
- 如何设计一个指标体系来衡量这个目标
- 怎么评估一次营销活动的效果

### 数据建模

- 用户分层怎么做
- RFM 模型的原理和应用
- 如何预测一个用户的流失概率

### 工具

- Python 数据分析常用库
- Pandas 的 merge 和 join 的区别
- 如何用 Python 做数据可视化

## 三面（40 分钟，业务负责人）

- 你怎么理解数据分析师的价值
- 数据分析师和业务的关系
- 如果业务方不认可你的分析结论，你怎么办
- 你最近分析过什么有意思的数据

## 面试总结

### 考察重点

1. SQL 熟练：窗口函数、复杂查询是必备
2. 统计思维：AB 测试、假设检验要能实际应用
3. 业务理解：能从数据中发现业务问题
4. 沟通能力：能把分析结论讲清楚给业务方

### 准备建议

- 刷 SQL 题（LeetCode 数据库 + 牛客 SQL 篇）
- 复习统计学基础
- 准备 2-3 个完整的数据分析案例
- 了解目标公司的业务模式

### 结果

三面通过，拿到 offer。
